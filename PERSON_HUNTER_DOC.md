Документация API: Вакансии (v1)
API предоставляет методы для создания, редактирования, удаления и просмотра вакансий. Ответы API стандартизированы: связанные данные (города, графики работы и т.д.) отдаются в виде готовых объектов с текстовыми названиями, что исключает необходимость делать дополнительные запросы к справочникам.
Базовый URL: https://api.personhunters.com/v1
Аутентификация
Для всех POST/PUT/DELETE запросов (а также для просмотра скрытых вакансий) требуется передавать токен пользователя в заголовках.
HTTP
Authorization: Bearer ТВОЙ_ACCESS_TOKEN
Content-Type: application/json
Мультиязычность
Система поддерживает мультиязычность "на лету".
Для получения данных (GET): Передайте нужный язык в Query-параметре ?lang=. Если параметр не передан, используется ru по умолчанию. При смене языка автоматически переводятся не только тексты вакансии, но и названия городов, отраслей, графиков работы и типов занятости.
Для сохранения данных (POST/PUT): Передайте параметр "lang" внутри тела JSON.

2. Получение списка вакансий
Возвращает список вакансий с поддержкой пагинации и выбора языка.
Метод: GET
Endpoint: /vacancies
Query-параметры:
lang (string) — Код языка (например, ru, uz, en).
page (int) — Номер страницы.
per-page (int) — Количество элементов на странице.
Пример запроса:
HTTP
GET /v1/vacancies?lang=uz&page=1

5. Редактирование / Добавление локализации
Позволяет изменить базовые данные вакансии или добавить перевод на другой язык.
Метод: PUT (или PATCH)
Endpoint: /vacancies/{id}
Сценарий А: Частичное обновление данных
JSON
{
    "pay_from": 6000000,
    "status": 0
}
Сценарий Б: Добавление Узбекского перевода Для добавления перевода к существующей вакансии достаточно передать параметр "lang" и текстовые поля. Числовые параметры (зарплата, город) дублировать не нужно.
JSON
{
    "lang": "uz",
    "vacancy_name": "PHP Dasturchi",
    "duties": "API yaratish va qollab quvvatlash",
    "requirements": "Yii2 framework bilan ishlash tajribasi",
    "conditions": "Masofaviy ish",
    "vacancy_description": "Kompaniya haqida..."
}
Ответ: Обновленный объект вакансии (HTTP 200 OK).
6. Удаление вакансии
Полностью удаляет вакансию и все её переводы. Заявки (отклики), привязанные к ней, сохраняются в системе, но помечаются как удаленные. Вы можете удалить только свои вакансии (если у вас нет прав администратора).
Метод: DELETE
Endpoint: /vacancies/{id}
Ответ: Пустое тело (HTTP 204 No Content).
Справочник кодов ошибок (HTTP Status Codes)
200 OK / 201 Created — Успешно.
204 No Content — Успешно удалено.
401 Unauthorized — Токен не передан, истек или недействителен.
403 Forbidden — Попытка изменить или удалить чужую вакансию.
404 Not Found — Вакансия не найдена, либо неверно указан URL (проверьте, что в URL есть множественное число /vacancies).
422 Unprocessable Entity — Ошибка валидации. В теле ответа придет массив с указанием некорректных полей (например, забыли обязательное поле).
